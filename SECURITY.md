# Security Policy

## Reporting a Vulnerability

Please report security issues **privately** — do not open a public issue.

- Preferred: open a private report via GitHub's
  [Report a vulnerability](https://github.com/pdrbrnd/tomo/security/advisories/new)
  (Security tab → Advisories).
- Or email **feedback@tomolibrary.com**.

I aim to acknowledge reports within a few days. Once a fix ships, the advisory
is published and I'm happy to credit you unless you'd rather stay anonymous.
